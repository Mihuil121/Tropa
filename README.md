# Тропа Навигатор — Офлайн-навигатор для условий подавления и подмены GPS

«Тропа Навигатор» — современное мобильное приложение для Android (React Native + Expo), предназначенное для надёжной навигации по дорогам, пешеходным тропам и городам. Приложение спроектировано для работы в условиях отсутствия сети Интернет, а также при активном глушении (джеминге) или подмене (спуфинге) спутникового сигнала GPS.

## 🌟 Как работает приложение

Навигатор не полагается исключительно на спутники GPS/ГЛОНАСС. Вместо этого он объединяет данные со всех доступных сенсоров смартфона с помощью **фильтра Калмана** и **фильтра частиц по форме дороги**:

1. **Определение режима движения**:
   - **Пешком**: ритмичный счётчик шагов, адаптивный шаг и замер азимута по компасу с автоматической компенсацией магнитных помех.
   - **В автомобиле (телефон в держателе/на сиденье)**: отслеживание поворотов по гироскопу, замер центростремительного ускорения в виражах, отслеживание остановок.
   - **В автомобиле (телефон в руке)**: фильтрация случайных движений руки от реального направления движения машины.

2. **Защита от подмены и глушения GPS**:
   - **Анализ радиосигнала**: отслеживание уровня сигнала $C/N_0$ и автоматической регулировки усиления $AGC$. У подменённого сигнала уровень мощности у всех видимых «спутников» одинаков — алгоритм это распознаёт и автоматически отключает неверный GPS.
   - **Автономное позиционирование**: использование задержки сигнала сотовых вышек (Timing Advance) и запоминание параметров сети при честном GPS.
   - **Фильтр частиц по изгибам дорог**: привязка текущего курса и пройденного расстояния к профилю дороги.

3. **Истинный оффлайн-роутинг по дорогам (A*)**:
   - Встроенный автономный модуль роутинга на алгоритме **A*** прокладывает путь строго по графу дорог, тротуаров и троп из файлов OpenStreetMap, предварительно сохранённых на устройстве. При отсутствии интернета маршрут **не строится по прямой сквозь здания**.

## 📱 Как пользоваться навигатором

### 1. Поиск и прокладка маршрута
- **Ввод адреса**: Нажмите на строку **«Куда поедем?»** в верхней части экрана и введите адрес, название улицы, города или заведения.
- **Указание точки на карте**: Просто зажмите пальцем нужное место на карте на 1 секунду.
- **Выбор транспорта**: В появившейся панели выберите режим:
  - 🚗 **Авто** — маршрут по автомобильным дорогам;
  - 🚶 **Пешком** — маршрут по тротуарам, пешеходным дорожкам и паркам;
  - 🛴 **Самокат** — маршрут с учётом велодорожек и асфальтированных дорожек.
- **Старт**: Нажмите зелёную кнопку **«В путь»** для начала ведения.

### 2. Подготовка к поездке без интернета (Офлайн)
- Нажмите кнопку **«Запланировать поездку без интернета»** под описанием маршрута.
- Навигатор автоматически скачает и сохранит в памяти телефона:
  - Векторные плитки карты коридора движения;
  - Дорожный граф OSM для автономного пересчёта пути;
  - Базу ориентиров сотовых вышек вдоль дороги.

### 3. Ручное управление при сильных помехах
Если GPS полностью заглушён и на экране появилась красная предупреждающая плашка, вам доступны кнопки ручной коррекции:
- **«Я здесь»**: коснитесь карты в точке вашего фактического местоположения (например, у заправки или перекрёстка);
- **«Поворот сейчас»**: нажмите в момент совершения реального манёвра, чтобы привязать позицию к повороту на маршруте.

## ⚙️ Структура настроек

Экран настроек разделён на 5 удобных категорий:

1. 🗺️ **Карты**:
   - Скачивание офлайн-карт городов и регионов.
   - Настройка подкачки данных в пути.
   - Импорт собственных файлов карт (`.pmtiles`), маршрутов (`.gpx`) и вышек (`cells.json`).
2. 🎨 **Вид и звук**:
   - Переключение темы оформления (**Системная**, **Светлая**, **Тёмная**).
   - Включение и отключение голосовых подсказок на русском языке.
3. 🚥 **Пробки**:
   - Ввод и активация ключа 2ГИС Routing API для отображения загруженности дорог.
   - Подключение дополнительных онлайн-слоев трафика при наличии интернет-соединения.
4. 📡 **Датчики**:
   - Управление локальной базой ориентации по сотовым вышкам и Wi-Fi.
   - Поиск и подключение внешнего Bluetooth OBD2-адаптера для получения точной скорости колёс.
5. ℹ️ **О приложении**:
   - Запуск экспресс-диагностики сигналов и датчиков перед выездом.
   - Сведения о защите персональных данных (**100% локальная обработка на устройстве**).
   - Сброс настроек к значениям по умолчанию.

## 🛠️ Сборка приложения (APK)

Для сборки готового установочного файла `.apk` выполните команду в терминале проекта:

```bash
bash build-local.sh
```

Скрипт автоматически проверит зависимости, выполнит сборку нативного проекта Android и скопирует готовый файл `Tropa.apk` на ваш рабочий стол.

## 🔒 Конфиденциальность и безопасность

Приложение работает исключительно в режиме приёма сигналов (пассивный локатор). Все обрабатываемые геоданные, сохранённые маршруты и параметры сотовых вышек остаются строго на вашем мобильном устройстве и не передаются на сторонние сервера.
